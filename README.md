# Тихо

Локальные инструменты для фото, скрытия данных, распознавания текста.

- До 10 JPG/PNG/WebP, по 30 МБ каждый.
- Ручные овальные и прямоугольные области с поворотом.
- Перетаскивание овалов мышью или пальцем; отмена перемещения.
- Размытие по Гауссу, мозаика, заливка; сила эффекта и растушёвка.
- Независимые настройки каждого фото, отдельное скачивание и общий ZIP.
- Масштаб колесом под курсором, перемещение средней кнопкой мыши.
- Сдержанная автокоррекция света и регулируемая виньетка.

Фотографии обрабатываются только в браузере и не отправляются на сервер. Перед публикацией проверьте все лица. Предпросмотр уменьшен для быстроты. Экспорт использует исходное разрешение, если пользователь не изменил размер или кадр. Исходные метаданные не сохраняются.

## Размещение

Статические файлы в корне. GitHub Pages: main, /(root). Все пути относительные, внешних CDN нет.

## Сторонние компоненты

Tesseract.js 6.0.1, Tesseract.js-core 6.0.0 и rus/eng tessdata используются локально; лицензия Apache 2.0 в TESSERACT-LICENSE.txt. Коррекция, кадрирование, Gaussian blur и ZIP реализованы локально. Области скрытия поддерживают независимые эффекты, размер и поворот.
