# Тихо

Приложение для локального размытия лиц на фото.

- До 10 JPG/PNG/WebP, по 30 МБ каждый.
- Автопоиск лиц и ручные овальные области.
- Перетаскивание овалов мышью или пальцем; отмена перемещения.
- Размытие по Гауссу, мозаика, заливка; сила эффекта и растушёвка.
- Независимые настройки каждого фото, отдельное скачивание и общий ZIP.

Фотографии обрабатываются только в браузере и не отправляются на сервер. Перед публикацией проверьте все лица. Большие снимки уменьшаются до 4096 px и 12 Мп. Исходные метаданные не сохраняются.

## Размещение

Статические файлы в корне. GitHub Pages: main, /(root). Все пути относительные, внешних CDN нет. WASM хранится сжатым gzip и распаковывается клиентом после проверки сигнатуры.

## Сторонние компоненты

MediaPipe Tasks Vision 0.10.21 и BlazeFace short-range, Google. Лицензия Apache 2.0 в MEDIAPIPE-LICENSE.txt. Gaussian blur и ZIP реализованы локально.
